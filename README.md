Данное веб-приложение разработано в качестве дипломной работы по теме "Разработка веб-приложения для автоматизации построения выкроек плечевых изделий для вязания" и представляет собой приложение-помощник, которое содержит:
- конструктор для построения пользовательских выкроек, которые пользователь может в дальнейшем изменять, а также размещать на них свои схемы;
- редактор схем, где пользователь сможет создавать свои собственные узоры для изделия, которые в дальнейшем сможет размещать на выбранных выкройках;
- генерацию описания работы по рядам, понятную для пользователя с указанием количества и места убавок и прибавок. Должно учитываться наличие схем на выкройках при генерации порядного описания;
- запоминание текущего прогресса пользователя и ведение учетам времени работы над изделием.
  
Для запуска приложения необходимо создать файл appsettings.json в папке /KnittingApp со следующей структурой:

{
  "ConnectionStrings": {
    "DefaultConnection": "Host= ;Username= ; Password= ;Database= "
  },
  "Jwt": {
    "SecretKey": ",
    "Issuer": "knittingapp.server",
    
    "Audience": "knittingapp.client",
    
    "AccessTokenExpirationMinutes": 15,
    
    "RefreshTokenExpirationDays": 7
  },
  "Logging": {
    "LogLevel": {
    
      "Default": "Information",
    
      "Microsoft.AspNetCore": "Warning"
    }
  },
  "AllowedHosts": "*"
}

В этом файле необходимо указать  сведения о базе данных в строке подключения DefaultConnection, а также указать SecretKey для JWT.
После необходимо провести миграции в указанную базу данных:

dotnet ef database update
